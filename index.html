Integration Guide

This RAG backend is built as a microservice framework. You can interface with it using any HTTP client. Below are the key endpoints to integrate into your application:

POST

/api/sessions

curl -X POST "http://localhost:8000/api/sessions" \
  -H "accept: application/json" \
  -H "Content-Type: application/json" \
  -d '{
    "session_id": "session_abc123",
    "title": "My Research Session"
  }'
POST

/api/upload

curl -X POST "http://localhost:8000/api/upload" \
  -H "accept: application/json" \
  -H "Content-Type: multipart/form-data" \
  -F "session_id=session_abc123" \
  -F "file=@/path/to/your/document.pdf"
POST

/api/query

curl -X POST "http://localhost:8000/api/query" \
  -H "accept: application/json" \
  -H "Content-Type: application/json" \
  -d '{
    "session_id": "session_abc123",
    "question": "What is the summary of the uploaded documents?"
  }'
GET

/api/sessions/{session_id}/documents

curl -X GET "http://localhost:8000/api/sessions/session_abc123/documents"
GET

/api/history

curl -X GET "http://localhost:8000/api/history?session_id=session_abc123&limit=10"
